> **Готовое коммерческое решение (Turnkey Micro-Product)** для салонов красоты, барбершопов, частных мастеров (маникюр, массаж, ресницы, косметология) и сервисных студий. Позволяет клиентам записываться онлайн 24/7 в Telegram без звонков и администраторов, а владельцам бизнеса — управлять расписанием, базой клиентов и рассылками прямо из мессенджера.

---

## 🎯 Какую боль бизнеса решает проект?

1. **Потеря клиентов в нерабочее время:** до 40% клиентов хотят записаться вечером или ночью, когда администраторы спят. Бот принимает запись круглосуточно.
2. **Ошибки и накладки (овербукинг):** алгоритм автоматически проверяет занятость слотов мастера и предотвращает двойные записи.
3. **Экономия на подписках CRM (YClients, Fresha, Dikidi):** экономит от 2 500 до 8 000 ₽ / $40-$100 ежемесячно.
4. **Удержание клиентов:** бот сохраняет контакты всех клиентов в базу, позволяет выгружать отчеты в Excel и запускать промо-рассылки в один клик.

## ✨ Ключевые возможности

### 👤 Для клиентов
* **Интуитивный пошаговый визард:** выбор категории услуги, мастера, удобной даты и свободного слота.
* **Умный расчет слотов:** бот учитывает длительность конкретной услуги, рабочий график салона (напр. 10:00–20:00) и исключает пересечения.
* **Защита от овербукинга:** атомарная проверка доступности интервала.
* **Личный кабинет («Мои записи»):** клиент видит активные записи и может отменить визит в 1 клик, освобождая время для других.
* **Быстрый доступ:** контакты, адрес салона, прайс-лист.

### 👑 Для владельца бизнеса / Администратора (`/admin`)
* **Автоматические уведомления:** моментальное оповещение с контактами клиента при создании или отмене записи.
* **График на сегодня:** список всех визитов дня с именами, услугами и телефонами.
* **Выгрузка базы в Excel (CSV):** генерация файла с полной историей записей с поддержкой русского языка (UTF-8-BOM).
* **Управление каталогом услуг:** добавление новых услуг и цен прямо в чате без правки кода или перезапуска бота.
* **Маркетинговые рассылки:** отправка спецпредложений, скидок и акций всем зарегистрированным клиентам.

## ⚡ Быстрый старт за 3 минуты

### 1. Клонирование и настройка окружения
```bash
git clone https://github.com/Max/telegram-booking-bot.git
cd telegram-booking-bot

# Создайте файл переменных окружения
cp .env.example .env
```

Отредактируйте `.env`:
```ini
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id_числом
SALON_NAME="Beauty Studio Elegance"
SALON_ADDRESS="ул. Арбат, 25, Москва"
SALON_PHONE="+7 (999) 000-00-00"
```

### 2. Запуск локально
```bash
# Создание виртуального окружения
python -m venv venv

# Активация:
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск тестов
pytest -v

# Запуск бота
python -m app.main
```

### 3. Запуск через Docker
```bash
docker-compose up -d --build
```
